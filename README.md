# Homo Studentus Pomytus

Шутливый сайт в стиле **National Geographic**, посвящённый редкому виду — ленивому студенту, который отказывается ходить на пары.

Проект создан ради троллинга друга. Есть две версии страницы:

| Страница | Описание |
|----------|----------|
| `index.html` | Мягкая (цензурная) версия |
| `fullversion.html` | Версия **без цензуры** — с матом и жестью  |

---

---

## Как запустить

Просто откройте `index.html` в браузере.

Никаких сборщиков, Node.js или сервера не требуется — это чистый HTML/CSS/JS.

---

## Что внутри

### Мягкая версия (`index.html`)
- Карточка вида *Homo Studentus Pomytus*
- Физиологические показатели (лень ≈ 98%)
- График суточной активности
- Карта «миграции» по комнате общежития (холодильник / микроволновка / пары)
- Полевые дневники

### Версия без цензуры (`fullversion.html`)
- Всё то же самое, но злее
- Красная цветовая схема
- Мат, усиленный роаст и дополнительные разделы
- Ещё более убийственная статистика
- Заключение экспедиции

Обе страницы связаны ссылками друг на друга.
